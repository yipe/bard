Bard

Live transcripts and a growing campaign wiki for your in-person D&D table, from one shared microphone.

Everything runs on your Mac: speech-to-text, speaker recognition and the AI. No audio or text leaves the machine.

What it does

Live transcript

Who is speaking and what they said, as the game happens.

No setup recording

Name a voice once, mid-game; an optional 15–30 second sample helps quiet players.

Character voices

A GM’s distinct NPC voice can be its own character.

Names spelled right

Bard learns your campaign’s names and fixes misheard ones, keeping what was heard.

Campaign wiki

Session write-ups, facts and new names, as plain Markdown you can edit in Obsidian.

Ask about the campaign

Ask a question; Bard searches every transcript and note and shows its sources.

Private by design

  • Runs on one Apple Silicon Mac. No account, no cloud or subscription required.
  • Recordings and voiceprints stay in a folder on your Mac. Ask your table before you record.
  • Bard Cloud backup is optional and off until you connect it.

What you need

  • A Mac with Apple Silicon
  • LM Studio for spelling cleanup and write-ups (transcription works without it)
  • A free Hugging Face account (speaker-recognition model)
  • A microphone in the middle of the table (an omnidirectional or boundary mic works best)

Install

Bard is open source and installs from the command line:

git clone https://github.com/yipe/bard && cd bard
yarn setup                         # uv sync + pnpm install
yarn build                         # build the web UI
lms server start --port 1235 && lms load google/gemma-4-26b-a4b-qat --yes   # or use the LM Studio app
HF_TOKEN=hf_… yarn start           # → http://127.0.0.1:8765

Full instructions: README on GitHub
